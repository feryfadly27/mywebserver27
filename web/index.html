Panduan Domain Lokal di Windows

Agar domain kustom seperti toko.test dapat diakses di browser Anda, Windows perlu mengetahui bahwa domain tersebut mengarah ke komputer lokal Anda (127.0.0.1).

  1. Buka Notepad sebagai Administrator (klik kanan Notepad → Run as administrator).
  2. Buka berkas: C:\Windows\System32\drivers\etc\hosts
  3. Tambahkan baris berikut di paling bawah file:
127.0.0.1  toko.test
127.0.0.1  proyekku.test
Klik "Yes" saat muncul konfirmasi Administrator (UAC) Windows.
